# Название моей выпускной работы

## Актуальность
Дворовые пространства российских городов и поселений часто не выполняют функцию полноценных общественных мест, что приводит к их деградации, социальной разобщенности жителей и конфликтам между разными группами населения (детьми, пожилыми, автомобилистами). Исследование потенциала трансформации дворов в инклюзивные общественные пространства актуально как для повышения повседневного качества жизни миллионов людей, так и для разработки эффективных механизмов вовлечения граждан в со-проектирование и со-управление городской средой.

## Цель исследования
Выявить и систематизировать физические, социальные и управленческие условия, при которых дворовое пространство может реализовать свой потенциал как полноценное общественное пространство, удовлетворяющее интересы различных групп населения. На основе полученных данных разработать практические рекомендации для муниципальных властей, управляющих компаний и активных жителей по созданию и развитию дворов нового типа.
